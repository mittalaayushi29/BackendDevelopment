# BACKEND-DEV.

## Simple CMS – Backend Development Lab

### Project Brief

**Simple CMS** is a Blog Content Management System developed as part of the Backend Development Lab assessment. The application is built using **Python Flask**, **MongoDB**, **PyMongo**, and **Jinja2**.

The application allows users to create and read blog posts. Each post contains a **title, content, author, and creation date/time**. The creation timestamp is automatically generated by the backend, while MongoDB automatically assigns a unique `_id` to every post.

### Features

- View all blog posts
- Create a new blog post
- Server-side validation for title, content, and author
- Automatic creation date and time
- Clickable post titles
- View the complete content of an individual post
- Retrieve individual posts using MongoDB `_id`
- Persistent storage using MongoDB
- Server-side rendering using Jinja2

### Technology Stack

- **Backend:** Python, Flask
- **Database:** MongoDB
- **MongoDB Library:** PyMongo
- **Template Engine:** Jinja2
- **Frontend:** HTML5, CSS3
- **Version Control:** Git & GitHub

### Installation and Execution

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd cms-project
```

3. Install the required Python packages:

```bash
pip install -r requirements.txt
```

4. Make sure the MongoDB server is running.

5. Run the Flask application:

```bash
python app.py
```

6. Open the application in a browser:

```text
http://127.0.0.1:5000
```

### Main Routes

| Method | Route | Purpose |
|---|---|---|
| GET | `/` | Display all posts |
| GET | `/posts` | Display all posts |
| GET | `/posts/new` | Display the create-post form |
| POST | `/posts` | Create a new post |
| GET | `/posts/<post_id>` | Display an individual post |
