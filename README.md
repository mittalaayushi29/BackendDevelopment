# Backend Development

This repository contains laboratory experiments, practice programs, and assessment projects completed as part of the **Backend Development** course.

The repository documents the progression from fundamental web technologies such as HTML, CSS, and JavaScript to backend development using Python, Node.js, server-side templates, databases, sessions, and web application development.

- Web APIs

## Laboratory Experiments

### Experiment 01 – HTML5 Elements

Creation of a structured HTML5 web page demonstrating semantic elements, forms, tables, lists, multimedia elements, accessibility features, and modern HTML5 input types.

### Experiment 02 – Cascading Style Sheets

Implementation of Inline, Internal, and External CSS along with element, class, and ID selectors and responsive styling.

### Experiment 03 – Responsive Web Design

Development of a responsive webpage from scratch using HTML5, CSS3, Flexbox, and Media Queries without using an external CSS framework.

### Experiment 04 – Bootstrap and Tailwind CSS

Implementation of the same responsive webpage using Bootstrap and Tailwind CSS to understand framework-based responsive design and utility classes.

### Experiment 05 – JavaScript Arrays, Objects and Functions

JavaScript programs demonstrating arrays, objects, functions, iteration, object methods, and arrow functions.

### Experiment 12 – Sessions and Cookies

Implementation of session and cookie management using Node.js and Express to demonstrate state management in web applications.

## Mid-Semester Lab Project – Simple CMS

The repository also contains a **Simple Blog Content Management System** developed for the Backend Development Lab assessment.

The CMS is implemented using:

- Python
- Flask
- Jinja2
- MongoDB
- PyMongo
- HTML
- CSS

### CMS Features

- Create blog posts
- Display all posts
- View individual posts
- Server-side form validation
- Automatic creation timestamps
- MongoDB persistent storage
- MongoDB ObjectId-based post retrieval
- Server-side rendering using Jinja2
